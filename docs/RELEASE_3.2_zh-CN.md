# fMOST Brain Viewer 3.2

[English](RELEASE_3.2.md) · [用户指南](USER_GUIDE_zh-CN.md)

3.2 增加自动更新提醒，以及下载、安装、重启恢复会话的更新流程。对于从 3.0 升级的用户，
本版同时包含 3.1.x 的渲染优化和只读 SWC 部分加载功能。

## 更新方式

- 软件运行时，每天最多检查一次 GitHub 正式版本。新版提醒不打断当前场景，可选
  Update now、Later 或 Skip this version。在 **Settings > Software updates...**
  可关闭自动检查，手动检查入口保留。
- 用户选择更新后后台下载安装包，支持重试、断点续传，并核对 Release 的 SHA-256。
  已完整下载的缓存安装包也须通过校验才能复用。
- 打包的 Windows 软件会先保存更新恢复快照，再原位安装。成功后自动重启，恢复
  场景、原 session 保存路径以及尚未保存的状态。
- 图谱、派生缓存、设置、原始 SWC/CSV/NRRD 数据和已保存 session 保留。正常升级
  不需要重新下载图谱。

关闭软件期间不会收到通知。其他电脑需先安装一次 3.2 或更新版本，才具备今后的自动
提醒功能。从 Python 源码运行时，请手动使用下载的安装包。

## 同时包含的渲染与 SWC 改进

axon 使用 GPU 实例化线段，调粗细时无需反复展开全部圆管网格。紧凑解析器减少临时
内存占用。固定 axon 几何预算默认关闭，可按需开启，与解析阶段的限制分开计算。
实测负载、性能结果及线段连接处的外观差异见[渲染说明](RENDERING_3.1.md)；大型数据
仍需相应内存和 GPU 计算。

损坏的 axon SWC 可显示剩余有效部分，不修改原文件。列表显示 `[Partial]`，通过
**File > SWC load diagnostics...** 可查看跳过的记录和缺失父节点连接。无效记录、
含糊的重复 ID 和环内连接会被排除，不猜测补全。诊断不能重建缺失坐标，也不能完整
列出已经彻底丢失的内容。soma 和分析用解析仍保持严格校验。

本版还包含 session 重新打开、隐藏 actor 释放、soma 索引、图谱标签解码、导出内存
和文件原子写入等修复，详见[更新记录](../CHANGELOG.md)。

## 数据与网络行为

自动检查仅查询 GitHub 的公开版本信息，不上传数据集或 session 内容。关闭自动检查后
不再定期发出这些请求，手动更新和图谱下载仍可使用。输入文件保持只读；恢复快照和
日志保存在本机，其中可能包含本地路径。
