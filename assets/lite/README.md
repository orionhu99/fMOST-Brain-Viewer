# Lite brand assets

This directory preserves the simplified line-art identity that preceded the
current full application logo. It is intentionally not referenced by the main
application or installer. The files are reserved for a possible lightweight
edition or other small-format uses.

- `fmost_brain_lite_logo_final_black.png`: approved black-background master
- `fmost_brain_lite_logo_final_transparent.png`: transparent master
- `fmost_brain_lite_logo.png`: application logo layout
- `fmost_brain_lite_icon.png`: square icon master
- `icon_sizes/`: 16–256 px raster icon set
- `fmost_brain_lite_viewer.ico`: multi-resolution Windows icon
